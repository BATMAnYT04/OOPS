# OOPS! Event Brand Website

A responsive, single-page event brand website built with plain HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser.

## Publish free with Cloudflare Pages
1. Create a GitHub repository and upload `index.html`.
2. In Cloudflare, open Workers & Pages → Create → Pages → Connect to Git.
3. Select the repository. Framework preset: None. Build command: leave blank. Build output directory: `/`.
4. Deploy. Add your custom domain under the Pages project's Custom domains tab.

## Before launch
- Replace the TBA event cards with confirmed event details, venue, date and ticket information.
- Replace the gallery placeholders with real event photos you have permission to use.
- Add your official Instagram and WhatsApp URLs in the footer.
- Connect the sign-up form to Formspree, Netlify Forms, or your own backend. The current form validates input and shows a demo confirmation, but does not transmit or store submissions.
- Add a privacy notice and any event-specific entry/age policies that apply.

No framework or build step is required.
